# Overlay skills

These **30** skills extend the upstream [ops-engineering-skills](https://github.com/selvarajmurugesan90/ops-engineering-skills) catalog with a deeper, runbook-oriented DevOps library (12-section `SKILL.md` format).

Installed automatically by `./install` after upstream skills. If a skill name already exists from upstream, the extra is skipped unless you pass `--prefer-extras`.
